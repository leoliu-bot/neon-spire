# 霓虹之井 / NEON SPIRE

版本 5.0.0 · 2026-09-23

GitHub 仓库保存可重建源码、原创素材与测试。无需构建的离线游戏可从 [v5.0.0 发行附件](https://github.com/leoliu-bot/neon-spire/releases/tag/v5.0.0) 下载；下载后用 Chrome 或 Edge 打开 HTML。仓库默认私有，需要有访问权限的 GitHub 账号。

一款原创竖屏街机游戏：建设六房间基地，乘电梯进入掩体战场，每局带回 10 枚晶核；战后电梯直接送往推币机，瞄准移动的放大器投放晶核，将生成的金币推入收集槽，再用收入扩建基地。

本版将转化机统一为枪灰、军绿与象牙色军事科幻设备，新增基地金币漏斗、招募中心、火箭筒与加特林角色，以及最多三人的出击编队。此前的八档瞄准、分段换弹、×5 / ×10 放大器、20 级房间、每局 10 核和完整电梯转场继续保留。

## v5 招募与编队

原聚变反应堆改为招募中心，旧存档保留原房间等级，原能源加成替换为每级小队攻击 +2%。点击房间或基地「招募」进入；先花 32 合金币建设，再支付金币招募指定角色，每人仅能招募一次、永久拥有，并自动加入空槽。旧存档默认仍只有火花。

| 驾驶员 | 招募费用 | 武器 / 定位 | 弹匣 | 发射间隔 | 换弹 | 基础单发伤害 |
| --- | --- | --- | --- | --- | --- | --- |
| 火花 / SPARK | 初始拥有 | 双相步枪，精准突击 | 24 | 0.15 秒 | 1.15 秒 | 9 |
| 余烬 / EMBER | 42 合金币 | 破城火箭筒，范围轰击 | 4 | 1.05 秒 | 2.10 秒 | 36 |
| 雷霆 / VOLT | 64 合金币 | 六管加特林，持续压制 | 120 | 0.05 秒 | 2.60 秒 | 3 |

火箭有实际飞行过程，爆炸半径 2.35 个场景单位；瞄准敌群间空地也可伤害范围内多个目标。加特林射速最高、单发伤害最低、弹匣最大。新角色使用原创持枪插画、局部瞄准变形、后坐与各自装填部件动画。

出击按钮上方有三个槽位，点击头像更换或移除人员；最多上阵三名不同驾驶员，至少一名才能出击。战斗中点击头像或按 1 / 2 / 3 切换主控；主控居中，其他人站在两侧。按住瞄准时，主控全额伤害、队友以 45% 伤害协同射击；松手全队隐蔽。每人独立弹匣、射速与换弹，切换不会补弹或重置冷却，编队自动保存。

基地顶部金币漏斗与实际钱包同步，币堆随余额变化。推币收入播放流入动画，在其他楼层获得的收入会保留反馈、返回基地时显示。此处展示已经入账的钱，无需再次领取；装饰币最多显示 48 枚，实际数额以数字为准。

## 开始游戏

发行文件 `霓虹之井.html` 已内嵌代码和资源。使用支持 WebGL 2 的 Chrome 或 Edge 打开即可游玩，无需安装、账号或网络；Windows 也可双击 `开始游戏.cmd`。首次交互后启用声音，设置中可切换流畅画质、静音与全屏。

存档保存在当前浏览器本地。更换浏览器、文件位置或清除网站数据，可能无法继续原存档。新存档初始晶核为 0；旧存档首次迁移时，原晶核库存保留至多 10 枚，多出的部分不结转。已有房间、装备、合金币和蓝图继续保留。漏斗剩余量逐次保存，刷新后优先进入推币层，继续未完成的投币。

## 游玩循环与操作

循环为：**基地 → 电梯 → 战斗 → 电梯 → 推币机 → 空漏斗提示 → 电梯 → 基地**。

| 场景 | 操作 |
| --- | --- |
| 零号基地 | 点击剖面房间或「房间建设」建造、升级；通过「招募」购买驾驶员，三个头像槽编辑编队，点击「小队出击」准备战斗 |
| 掩体战斗 | 点击点射；按住并拖动鼠标或手指持续瞄准射击；松手进入掩体 |
| 换弹与技能 | 松手后自动换弹，弹匣打空也会装填；R 或「换弹」手动装填；空格或「超载脉冲」释放技能 |
| 倍率推币 | 观察横移的 ×5 / ×10 装置，点击选择落点并投放晶核；横拖调整位置，按住连续投放，也可使用左、中、右快捷位置和投币按钮 |
| 投币完成 | 漏斗归零后不能继续投币，显示「前往基地建设」；已进入台面的硬币继续运动、结算 |
| 楼层导航 | 待机时点击楼层按钮、按 ↑/↓ 或上下滑动；每次切层都有电梯过场，战斗期间禁止切层 |

电梯过场约 2.52 秒：关门 0.42 秒、运行 1.48 秒、开门 0.62 秒。过场期间锁定操作，目的地在舱门完全闭合后切换。战斗结算短暂停留后自动前往推币机，也可点击结算按钮提前进入转运。

## 掩体战斗

战场采用前景驾驶员与实体掩体、远处敌人的正面构图。瞄准决定是否命中，敌人发光核心提供弱点伤害；红圈表示敌人正在准备攻击。小队共享生命与掩体耐久，只要有人仍在射击就按暴露状态受伤；全队隐蔽或全部装填时由掩体吸收部分伤害，掩体也会损坏。

火花使用四张原创持枪姿态图，结合左右镜像形成八档瞄准姿态，并在档位内校正持枪角度；枪口位置随可见枪械变化。射击时，枪、肩部、腰胯和马尾分别响应后坐力。火花换弹沿用收枪、卸匣、插匣和复位阶段，两张独立换弹图配合网格变形。动画属于插画驱动的分段表现。

各武器容量、射速与换弹见上表，超载脉冲冷却 14 秒。单局最多 38 秒，出击能源不足时缩短；精英在后段出现，生命降至一半后进入过载阶段，击破可获得蓝图。结算展示击破数与命中率。

**每次正常结算固定获得 10 枚晶核，包括角色被击败的结算。**击破数量不会再额外增加晶核，基地不被动生产晶核。漏斗未投完时不能开始下一局。

## 漏斗、放大器与金币台

转化机采用磨损装甲、钢板与少量冷青状态灯，流程铭牌依次标明「晶核输入 → 扫描分解 → 金币成形 → 落币输送」。晶核触碰放大器会出现扫描碎片，再生成金属金币；设备外壳取消彩色赌场灯带与金边拱牌。

战后抵达推币层，10 枚晶核汇入机台上方漏斗；装载动画完成后才能投放。每次投币消耗漏斗中 1 枚晶核，没有自动卸币或额外补币。漏斗归零后由玩家点击提示前往基地，台面落币继续结算。

投入口下方有两个左右移动的放大器：上方 ×5，下方 ×10。晶核首次碰到装置后，分别生成 5 枚或 10 枚实体金币；同一枚晶核只触发一次，不会叠乘。未碰到任何装置时生成 1 枚金币。生成金币不会直接增加库存，它们需要进入底部推币台后继续被推动。

底部采用一个往复推板和 Cannon ES 刚体金币。只有越过台面前沿并落入收集区的金币才入账，**每枚实体金币增加 1 合金币**；侧面溢出不兑换。同批推落的多枚金币按实际枚数逐枚入账。

新存档一次性提供 63 枚台面初始币，在首次消耗晶核投币前暂停物理推进；首次投币后启动，并在切换至基地或战场时继续运行。台面最多同时容纳 240 枚实体金币，尚未进入台面的生成金币等待空位。漏斗余量、飞行晶核、待生成金币、推币启动状态与未结算金币数量保存到本地；刷新时恢复进度、重建币堆，不重复发放初始币。关闭页面时不模拟离线物理掉落。

机台界面显示放大器状态、推板行程与当前币数。「本次铸金」统计本次打开游戏期间实际落入收集区的收益，刷新后重新计数，不影响已入账合金币。

## 基地房间

六个房间每间最高 20 级，指挥中心与能源工坊初始建成。所有房间顶部铭牌显示当前等级及上限，例如 `LV.01 /20`；未解锁房间显示 `LV.00 /20`。旧存档的房间等级保留，可继续升级至新上限。

未解锁房间在金币足够建造时显示右上角红点；已建成房间在未满级且金币足够升级时显示红点。招募中心还有可负担的未招募角色时，满级也保留红点。提示随余额实时更新，成功建设或升级后播放设施动画。

| 房间 | 初始状态 / 解锁费用 | 成长效果 |
| --- | --- | --- |
| 指挥中心 | 已建成，1 级 | 每次升级攻击 +6% |
| 能源工坊 | 已建成，1 级 | 每次升级基础产能 +14% |
| 武器研究室 | 12 合金币 | 每级攻击 +18% |
| 装甲实验室 | 18 合金币 | 每级护甲系数 +20%，并增强掩体减伤 |
| 合金铸造室 | 24 合金币 | 每级每 12.5 秒产出 1 合金币 |
| 招募中心 | 32 合金币 | 开放指定角色招募；每级小队攻击 +2% |

战斗加成在下一局开始时读取，生产加成立即生效。合金铸造室需要先付费建成，未满一枚的生产进度会保留。基地离线生产最多计入 15 分钟；装备入口提供仓库、武器强化及修复功能，后续武器强化需要蓝图。

房间升级费用为基础升级价乘以 `1.22^(当前等级−1)`，结果向上取整。指挥中心、能源工坊、武器研究室、装甲实验室、合金铸造室及招募中心的基础升级价依次为 14、12、18、22、30、36 合金币，解锁费用仍以表格为准。场景设施按等级阶段增加预建装饰，数字铭牌逐级更新。

## 开发与交付

项目使用 Three.js、Cannon ES 和 Vite。三种玩法各有独立的 `THREE.Scene`、正面相机与光照，共享一个 WebGLRenderer。原井道 Scene 保留在世界结构中，但不再常驻渲染；电梯由覆盖游戏画面的独立 DOM/CSS 模块呈现，不使用场景间的摄像机滑动。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

构建产物 `dist/index.html` 由 vite-plugin-singlefile 合并为离线单文件。

| 文件 | 责任 |
| --- | --- |
| `src/main.js` | 三场景切换、出击与投币流程、房间界面和屏幕输入 |
| `src/operators.js` / `src/squad-ui.js` | 三武器参数、金币招募、三槽编队与战斗切人 |
| `src/base-hopper.js` | 基地余额币堆、流入/消费反馈，显示实际账本而不重复入账 |
| `src/elevator-transition.js` / `.css` | 完整电梯遮罩、开关门、楼层读数及转场回调 |
| `src/world.js` | 三种玩法组装、保留的井道结构与动画协调 |
| `src/rooms.js` | 六房间内装、20 级铭牌、可建设红点及升级动画 |
| `src/mint-scene.js` | 机台外壳、漏斗展示与推进灯光 |
| `src/pusher.js` | 移动放大器、晶核碰撞、实体金币生成、底部推板及落币结算 |
| `src/battle-scene.js` | 废墟、掩体、八档持枪姿态、分段换弹与枪口位置 |
| `src/battle.js` | 瞄准射击、装填、伤害、敌人、技能与战斗结算 |
| `src/economy.js` | 资源、房间成长、固定晶核奖励、存档与迁移 |
| `src/assets/ART_NOTES.md` | 原创图像来源、提示词及使用方式 |

资源写入统一经过 Economy，推币收益由实际刚体的轨迹和落点验证。图像与设施采用原创设计，参考图片未直接嵌入游戏素材。

交付包含可玩的基地、掩体战斗与推币循环以及可修改源码；当前内容是一套重复成长玩法。实际验证结果见 [QA_REPORT.md](QA_REPORT.md)，依赖许可见 [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt)。QA 报告中的 `source/`、`预览/` 和 `测试记录/` 是完整本地交付包的目录；本仓库从源码目录开始，保留同一组测试与构建输入。
